# Data license

The dataset in this directory (`data/**`), and the static JSON API generated
from it (`site/public/v1/**`), are licensed under **Creative Commons
Attribution-ShareAlike 4.0 International (CC BY-SA 4.0)**:
<https://creativecommons.org/licenses/by-sa/4.0/>

When you reuse the data, attribute it as "Data from TechAPI" with a link to
<https://github.com/GetTechAPI/TechAPI>, and release derived datasets under the
same license. Each record also lists the sources it was compiled from in its
`source_urls` field.

## Images

`image_url` and `logo_url` only link to files on Wikimedia Commons. Those files
are not part of the dataset and this license does not cover them: each keeps
the license shown on its Commons file page. Records with a photo also store its
`image_license` and `image_attribution`; credit the author that way, or link
to the file page, wherever you display one.
